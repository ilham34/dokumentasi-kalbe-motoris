Canvasser (Motoris)

Dokumentasi alur kerja lapangan aplikasi SFA untuk canvasser/motoris: mulai dari login, check-in outlet, transaksi, dokumentasi aktivitas, setoran, hingga laporan aktivitas harian. Dokumentasi ini disusun sebagai penawaran awal solusi SFA untuk calon client.

Ringkasan Journey Harian Motoris
1. LoginMotoris masuk memakai username & password, sesi tersimpan untuk auto-login.
2. HomeMelihat jumlah kunjungan hari ini, status check-in, dan menu sesuai hak akses admin.
3. Check In OutletPilih toko terdekat berbasis GPS atau buat NOO jika diaktifkan admin, lalu upload foto check-in.
4. Aktivitas / TransaksiInput penjualan, pembelian, distribusi, foto activity, stok, PO, pengembalian, atau setor uang sesuai tipe outlet.
5. Check OutUpload foto check-out, koordinat tercatat, durasi kunjungan tersimpan.
6. MonitoringRiwayat masuk ke Log Produk, Log Uang, Log Activity, dan laporan website admin.
Menu Utama Aplikasi Android

Login & Session

Motoris login melalui aplikasi Android. Sistem menyimpan token dan id user untuk akses API. Jika sesi masih valid, pengguna dapat masuk otomatis. Jika password awal/perubahan diperlukan, diarahkan ke ganti password.

  1. Input username dan password.
  2. Server memvalidasi kredensial, level, token, dan menu aktif.
  3. Aplikasi membuka Home Panel.

Home Panel

Halaman utama menampilkan jumlah kunjungan hari ini, kartu Check In, dan menu transaksi yang muncul dinamis sesuai setting admin.

  1. Ambil info log harian dari server.
  2. Tampilkan status sudah/belum check-in.
  3. Tampilkan menu sesuai flag: penjualan, distribusi, foto, PO, stok, dan lainnya.

Check In Toko

Motoris wajib check-in sebelum transaksi. Aplikasi mengambil GPS, menampilkan Google Maps, melakukan reverse geocoding alamat, dan mewajibkan foto check-in.

  1. Aktifkan GPS dan izinkan lokasi.
  2. Pilih toko dari daftar terdekat berdasarkan koordinat.
  3. Upload foto check-in.
  4. Sistem simpan lat, lng, alamat, foto, waktu, user, dan toko.

NOO / Toko Baru

Jika admin mengaktifkan NOO, motoris dapat mendaftarkan outlet baru langsung dari lapangan.

  1. Pilih tab NOO pada Check In.
  2. Isi nama toko, group toko, type toko, DC toko, kelurahan, alamat, dan type lokasi.
  3. Upload foto outlet/check-in.
  4. Simpan & langsung check-in ke outlet baru.

Check Out

Setelah aktivitas selesai, motoris melakukan check-out sebagai bukti kunjungan selesai.

  1. Buka kartu Check In yang berubah menjadi Check Out.
  2. Ambil foto check-out.
  3. Sistem simpan koordinat, alamat, foto, jam selesai, dan durasi kunjungan.

Penjualan

Digunakan di outlet bertipe TOKO untuk mencatat penjualan produk.

  1. Masuk menu Penjualan setelah check-in.
  2. Klik tambah bukti penjualan.
  3. Sistem membuat nomor bukti/temp id.
  4. Pilih detail produk, input qty, harga, dan total.
  5. Simpan detail lalu posting/finalisasi.
  6. Status transaksi dan nilai penjualan muncul di web admin.

Pembelian

Digunakan pada outlet bertipe DISTRIBUTOR untuk mencatat pembelian barang dari distributor.

  1. Pilih menu Pembelian.
  2. Tambah bukti pembelian berdasarkan tanggal check-in.
  3. Input item produk, kuantitas, dan nilai.
  4. Simpan detail dan posting.
  5. Data masuk laporan pembelian dan log produk.

Input PO

Mencatat Purchase Order dari outlet/distributor sebagai rencana pemesanan.

  1. Buka menu Input PO.
  2. Tambah transaksi PO.
  3. Pilih produk dan isi jumlah order.
  4. Simpan detail item.
  5. Kirim/posting agar dapat dipantau admin.

Pengembalian

Mencatat retur/pengembalian produk dari outlet/distributor.

  1. Buka menu Pengembalian.
  2. Tambah bukti pengembalian.
  3. Pilih barang yang dikembalikan.
  4. Isi quantity dan keterangan kondisi.
  5. Simpan dan posting untuk masuk laporan retur.

Setor Uang

Mencatat setoran uang hasil penjualan. Data setoran mendukung bukti foto dan status transaksi.

  1. Buka menu Setor Uang.
  2. Tambah bukti setor.
  3. Isi detail nominal/setoran manual bila tersedia.
  4. Upload foto bukti setor.
  5. Simpan dan posting agar muncul di Log Uang dan laporan setor.

Distribusi Produk

Checklist ketersediaan produk per SKU di toko, termasuk pembanding dengan produk kompetitor jika disiapkan master datanya.

  1. Buka menu Distribusi Produk.
  2. Tambah bukti distribusi untuk toko yang sedang dikunjungi.
  3. Pilih produk dan isi status ketersediaan.
  4. Simpan detail dan posting.
  5. Admin melihat rekap penetrasi produk per toko/area.

Distribusi Kategori

Checklist distribusi berdasarkan kategori/kelompok produk untuk membaca coverage kategori di outlet.

  1. Buka Distribusi Kategori.
  2. Tambah bukti kunjungan.
  3. Pilih kategori dan isi status distribusi.
  4. Simpan dan posting.
  5. Data masuk laporan rekap checklist kategori.

Foto Activity Motoris

Dokumentasi foto aktivitas promosi/display/branding oleh motoris.

  1. Buka Foto Activity Motoris.
  2. Tambah bukti foto activity.
  3. Pilih jenis foto/remark bila tersedia.
  4. Ambil atau upload foto dari kamera.
  5. Simpan agar admin dapat memverifikasi aktivitas lapangan.

Foto Activity SMD

Dokumentasi aktivitas SMD dengan detail foto yang terpisah dari foto motoris.

  1. Buka Foto Activity SMD.
  2. Tambah master aktivitas.
  3. Isi detail/sub-detail foto SMD.
  4. Upload bukti foto.
  5. Data tampil di laporan foto activity SMD.

Input Stok

Input stok outlet untuk memantau ketersediaan barang di lapangan.

  1. Buka menu Input Stok.
  2. Pilih/ tambah transaksi stok.
  3. Pilih produk dan masukkan jumlah stok.
  4. Simpan data stok.
  5. Admin dapat melihat laporan stok dan status OOS.

Log Produk

Riwayat transaksi berbasis produk seperti penjualan, pembelian, stok, distribusi, dan pengembalian.

  1. Motoris membuka tab Log Produk.
  2. Pilih periode/data yang ingin dilihat.
  3. Sistem menampilkan transaksi produk yang pernah dibuat.

Log Uang

Riwayat transaksi keuangan seperti setor uang dan kas terkait aktivitas lapangan.

  1. Buka tab Log Uang.
  2. Lihat daftar transaksi nominal dan statusnya.
  3. Gunakan sebagai kontrol harian sebelum closing aktivitas.

Log Activity

Riwayat aktivitas kunjungan harian motoris: check-in, check-out, toko, dan aktivitas yang dilakukan.

  1. Buka tab Log Activity.
  2. Lihat daftar outlet yang dikunjungi.
  3. Cek durasi, status, dan aktivitas yang sudah tersimpan.

Profile

Menampilkan data pengguna seperti nama, jabatan, team, area/regional, serta menyediakan logout dan ganti password.

  1. Buka tab Profile.
  2. Cek identitas motoris.
  3. Gunakan ganti password atau logout jika diperlukan.

Setting Menu dari Website Admin

Menu Android tidak selalu sama untuk semua motoris. Website admin mengatur flag akses seperti menu_penjualan, menu_distribusiproduk, menu_fotoactivitymotoris, menu_inputpo, menu_setoruang, menu_inputstok, dan menu_inputijin.

  1. Admin membuat/ubah pegawai dan user.
  2. Admin menentukan jabatan, team, area, dan role.
  3. Admin mengaktifkan menu sesuai kebutuhan operasional.
  4. Aplikasi Android membaca konfigurasi saat Home dimuat.

Master Data Pendukung

Transaksi motoris bergantung pada master di website: barang, toko, pegawai, wilayah, group toko, type toko, DC toko, kategori, brand, satuan, reason, remark, dan jenis foto activity.

  1. Admin menyiapkan master data.
  2. Motoris memilih data melalui dropdown/search di aplikasi.
  3. Data transaksi tersimpan dengan referensi master yang konsisten.

Laporan Admin

Setiap aktivitas motoris tersinkron ke website admin untuk monitoring dan rekap.

  1. Laporan penjualan dan pembelian.
  2. Laporan CICO/kunjungan.
  3. Laporan foto activity motoris dan SMD.
  4. Laporan checklist distribusi produk/kategori.
  5. Laporan stok, OOS, PO, retur, setoran uang, dan ijin.

Input Ijin

Motoris dapat mengajukan ijin/cuti/sakit jika menu diaktifkan oleh admin.

  1. Buka menu Input Ijin.
  2. Isi tanggal, jenis ijin, alasan, dan lampiran bila diperlukan.
  3. Simpan pengajuan.
  4. Admin memantau melalui laporan ijin/approval.
