Alur Website Admin

Website digunakan oleh Admin / Manajemen untuk mengelola master data, memantau aktivitas sales lapangan, dan melihat laporan.

1

Login Admin

Admin masuk dengan username & password. Sistem memvalidasi level akses (Super Admin, Regional Sales Manager, Area Sales Manager, Team Leader, dll).

2

Dashboard Motoris

Menampilkan ringkasan: Peta aktivitas sales, grafik penjualan (Qty & Nominal), ranking penjualan per produk, distribusi, filter per Regional/Area/Team Leader/Sales.

3

Kelola Master Data

Admin mengelola: Master Barang, Toko, Pegawai/Karyawan, Regional, Area, Team Leader, Jabatan, Kategori Barang, Type Toko, Group Toko, DC Toko, Wilayah (Provinsi/Kabupaten/Kecamatan/Kelurahan).

4

Kelola Transaksi

Memonitor dan mengelola: Penjualan Produk, Pembelian Produk, Pengembalian Produk, Input PO, Setor Uang/Kas, Pindah Stok.

5

Monitoring Aktivitas Lapangan

Melihat data Check In/Check Out sales (foto, koordinat GPS, waktu, durasi), Peta lokasi real-time (Map Activity & Map Sales), Foto Activity Motoris & SMD.

6

Laporan

Laporan Penjualan, Laporan Kunjungan (CICO), Laporan Stok, Laporan Distribusi, Laporan Foto Activity, Laporan Ijin, Laporan Rekap, Ranking Penjualan, Export CSV/Excel.

7

Setting & User Management

Kelola User & Level Akses, Setting Menu per role, Otoritas Aplikasi, Identitas Perusahaan, Setting Reward Toko, Pengumuman, Firebase Notifikasi.

Alur Aplikasi Android (Sales Lapangan)

Aplikasi Android (Flutter) digunakan oleh Sales/Motoris di lapangan untuk check in ke toko, melakukan transaksi, dan dokumentasi aktivitas.

1

Splash Screen

Menampilkan logo Kalbe Motoris selama 1 detik saat inisialisasi aplikasi. Dark mode dengan aksen oranye.

2

Login

Input Username & Password. Auto-login jika sesi masih aktif. Tersimpan di SharedPreferences. Jika password baru, diarahkan ke halaman Ganti Password.

3

Home Panel (Bottom Navigation)

5 tab navigasi bawah: Home (Check In & Menu), Log Produk (riwayat produk), Log Uang (riwayat keuangan), Log Activity (riwayat aktivitas), Profile (data diri & logout).

4

Check In ke Toko

Sales memilih toko terdekat (berdasarkan GPS) atau membuat toko baru (NOO). Wajib foto Check In. Lokasi GPS & alamat otomatis tercatat. Peta Google Maps menampilkan posisi saat ini.

5

Menu Transaksi (Setelah Check In)

Menu muncul dinamis sesuai hak akses. Tersedia: Penjualan, Pembelian, Distribusi Produk, Distribusi Kategori, Foto Activity Motoris, Foto Activity SMD, Pengembalian, Input PO, Setor Uang, Input Stok, Input Ijin.

6

Transaksi di Toko

Penjualan: Pilih produk → input qty & harga → simpan detail → posting.
Pembelian: Catat pembelian dari distributor.
Distribusi: Checklist ketersediaan produk di toko vs kompetitor.
Foto Activity: Upload foto aktivitas promosi di toko.

7

Check Out

Setelah selesai, sales melakukan Check Out. Wajib foto Check Out. Lokasi GPS tercatat. Durasi kunjungan terhitung otomatis.

8

Kunjungan Berikutnya

Sales berpindah ke toko lain, ulangi proses Check In → Transaksi → Check Out. Jumlah kunjungan hari ini tercatat di Home.

Keunggulan vs Kompetitor

📍 GPS-Based Check In/Out

  • Validasi lokasi real-time dengan Google Maps
  • Deteksi lokasi palsu (mock location detection)
  • Foto wajib saat Check In & Check Out sebagai bukti
  • Pencatatan durasi kunjungan otomatis
  • Alamat otomatis dari geocoding (reverse geocoding)

🔐 Multi-Level Akses Hierarkis

  • Hierarki: SA → Regional → Sub-Regional → Team Leader → Cabang → Sales
  • Dashboard filter otomatis sesuai level user
  • Menu dinamis sesuai hak akses (konfigurasi per user)
  • Otoritas CRUD per menu (Add/Edit/Delete/Print)

📊 Dashboard Analitik Real-time

  • Grafik penjualan by Qty & Nominal (ApexCharts)
  • Ranking penjualan per produk
  • Penjualan per sales per produk
  • Analisa distribusi produk vs kompetitor
  • Filter multi-level: Nasional hingga per Sales

📱 Aplikasi Mobile Flutter (Cross-Platform)

  • Built dengan Flutter — performa native di Android & iOS
  • Dark Mode modern dengan UI yang intuitif
  • Offline-capable (SharedPreferences untuk session)
  • Auto-login untuk produktivitas sales

🏪 Manajemen Toko Lengkap (NOO Support)

  • NOO (New Open Outlet) — sales bisa daftarkan toko baru langsung dari lapangan
  • Toko terdekat otomatis berdasarkan radius GPS
  • Klasifikasi: Group Toko, Type Toko, DC Toko, Type Lokasi
  • Integrasi wilayah lengkap (Provinsi → Kelurahan)

📸 Dokumentasi Foto Aktivitas

  • Foto Activity Motoris & SMD dengan kategorisasi
  • Upload langsung dari kamera smartphone
  • Terintegrasi dengan data check in toko
  • Laporan foto activity lengkap di website admin

📈 Distribusi & Kompetitor Analysis

  • Checklist distribusi produk di setiap toko
  • Perbandingan produk sendiri vs kompetitor
  • Distribusi by produk & by kategori
  • Data real-time untuk strategi penetrasi pasar

🔔 Notifikasi & Komunikasi

  • Firebase Cloud Messaging untuk push notification
  • Pengumuman dari admin ke semua sales
  • Kirim pesan internal ke pegawai
  • Alert system untuk approval & posting

API Integration DMS Subdist

REST API berbasis JSON dengan autentikasi JWT untuk integrasi data antara sistem subdistributor dengan aplikasi DMS. Base URL: http://34.101.178.201

🔐
1. Authentication API

Sistem menggunakan JWT Token Authentication. Token wajib dikirim pada setiap request API.

POST /authenticate ⏱ Token berlaku 5 jam
Request Body
{
  "username": "subdist_test",
  "password": "test"
}
Response
{
  "token": "JWT_TOKEN"
}
Header (untuk semua API)
Authorization: Bearer <JWT_TOKEN>
📦
